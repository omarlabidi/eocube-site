# Site web EOCube

Page d'accueil d'Earth Observation Cube, servie sur https://eocube.io (puis eocube.ai).

- `index.html` : la page (scène 3D Three.js dans le héros).
- `assets/` : moteur 3D, textures de la Terre, logo.
- Déploiement : l'hébergement OVH (dossier `eocube2026`) est relié à la branche `main` de ce dépôt ; un push sur `main` met le site à jour.

À compléter dans `index.html` : e-mail de contact, téléphone, nom et rôle de Souha, lien LinkedIn, version EN.
